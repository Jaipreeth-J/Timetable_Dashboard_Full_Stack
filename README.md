# Timetable Dashboard

A full-stack web application designed for parsing complex university timetable documents and providing personal schedules.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18+)
- Firebase Project with Firestore enabled.

### 2. Installation
Install dependencies for both frontend and backend from the root directory:
```bash
npm run install-all
```

### 3. Firebase Configuration
- **Backend:** Update `backend/src/config/serviceAccountKey.json` with your Firebase Admin SDK service account key.
- **Frontend:** Update `frontend/src/firebase/config.js` with your Firebase project credentials.

### 4. Running the App
Run both frontend and backend concurrently from the root directory:
```bash
npm run dev
```

## 🏗️ Project Structure
- `backend/` - Node.js Express server.
- `frontend/` - React application built with Vite.
